# Bubble BDS Host v0.3.0

Pacote de interface baseado exatamente no design aprovado:
- ícone Bubble;
- splash de 3 segundos;
- instalador com console dominante e botão Instalar Tudo;
- console recolhível, expandido e tela cheia;
- auto-scroll acompanhando sempre o log mais recente;
- tela pós-instalação com Nome do mundo, Survival/Criativo, Cheats e Seed;
- botão Iniciar Servidor;
- caixa SAY removida;
- lógica PRoot/Debian/Box64/BDS preservada.

O script aplica os arquivos sobre o repositório atual e também gera um ZIP FULL do
repositório após o commit.
