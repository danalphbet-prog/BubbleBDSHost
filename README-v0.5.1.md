# Bubble BDS Host v0.5.1 — Minecraft-style UI font

Esta revisão aplica a fonte do projeto aberto `IdreesInc/Minecraft-Font`
em toda a interface visual da Bubble, mantendo o Console em fonte monoespaçada.

Fonte:
- projeto: https://github.com/IdreesInc/Minecraft-Font
- licença: SIL Open Font License 1.1
- commit fixado: 261ac77fbf28796ca09c22eb83ecdfe386c4b838
- arquivos usados: Minecraft.otf e Minecraft-Bold.otf

Observação:
O projeto da fonte é um projeto de fã, não afiliado à Mojang/Minecraft,
e recria visualmente a tipografia da interface sem incluir fontes do jogo original.

Aplicação:
- títulos, labels, formulários, botões, categorias, navegação e switches usam a fonte;
- estilos em negrito usam a variante Bold;
- saída do Console permanece monospace;
- campo de comandos do Console permanece monospace;
- há fallback seguro para a fonte padrão do Android.
