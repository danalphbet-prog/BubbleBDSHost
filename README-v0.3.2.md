# Bubble BDS Host v0.3.2 — Compact UI

Ajuste visual sobre a v0.3.1.

- Bubble do ícone menor e centralizada dentro de uma safe area maior;

- splash visualmente menor, preservando a paleta aprovada;
- tipografia geral reduzida em aproximadamente 15–20%;
- botões mantêm o mesmo estilo aprovado;
- lógica do BDS e retomada real do Box64 não foram alteradas.
